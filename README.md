# Data Analytics Project

## Overview

This project demonstrates an end-to-end Data Analytics workflow, starting from data collection and preprocessing to dashboard creation and business insights generation. The project uses Python for data analysis, SQL for database querying, and Power BI for data visualization.

---

## Dataset

The dataset contains business/customer-related information used for analytical purposes. It includes multiple attributes that help identify trends, patterns, and key performance indicators.

### Key Features

* Customer Information
* Transaction Details
* Product Categories
* Sales Metrics
* Date & Time Attributes

## Project Workflow

### 1. Data Loading

* Imported dataset into Python.
* Performed initial inspection of data structure and columns.

### 2. Exploratory Data Analysis (EDA)

* Checked dataset dimensions and data types.
* Generated summary statistics.
* Identified trends, patterns, and anomalies.
* Created visualizations for better understanding.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected data inconsistencies.
* Standardized formats where required.

### 4. Database Integration

* Created database and tables.
* Loaded cleaned data into PostgreSQL/MySQL/SQL Server.
* Executed SQL queries for analysis and reporting.

### 5. Power BI Dashboard

* Connected database/data source to Power BI.
* Created interactive dashboards and visual reports.
* Added KPIs, charts, filters, and slicers.

### 6. Reporting & Presentation

* Documented findings and business insights.
* Prepared a project report.
* Created a professional presentation using Gamma.

## How to Run

### Prerequisites

* Python 3.x
* PostgreSQL/MySQL/SQL Server
* Power BI Desktop

### Steps

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Install required Python libraries.

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2
```

3. Load the dataset into Python.

4. Perform EDA and data cleaning.

5. Import cleaned data into the database.

6. Run SQL queries for analysis.

7. Open the Power BI file (.pbix) and refresh the data source.

8. Review the dashboard and generated reports.
